# Security

## Reporting a vulnerability

If you discover a potential security issue in this project, notify AWS/Amazon Security via the
[vulnerability reporting page](http://aws.amazon.com/security/vulnerability-reporting/).
Please do **not** create a public GitHub issue.

## Scope

This repository is sample code. Review it, and adapt it to your security requirements, before using it
on a production site. The security design and its assumptions are documented in
[docs/threat-model.md](docs/threat-model.md); the deployment checklist is in the
[README](README.md#security).
